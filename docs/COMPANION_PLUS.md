# MyBigBlueFish 修改说明

本仓库基于 [Bai-Cute/big-blue-fish-desktop-pet](https://github.com/Bai-Cute/big-blue-fish-desktop-pet) 的 v1.0.5（Apache License 2.0）修改。原作者的代码、动画素材（来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，MIT）、许可文件和第三方声明均保持不变；下面列出本仓库新增和修改的内容。

修改后的程序在设置页左侧显示版本号 `1.0.5-companion.4`（构建时传入 `-p:InformationalVersion=1.0.5-companion.4`）。所有新增数据都只保存在本机安装目录的 `data\` 中，不上传。

## 一、沿屏幕四周爬行

- 鱼鱼用「螃蟹走路」动作沿当前显示器的可用区域（不含任务栏）四周横着爬：底边站立，左右两侧贴墙（旋转 ±90°），顶边倒挂（180°），拐角处顺势转身且始终贴着两条边。
- 设置 → 陪伴与外观 →「沿屏幕四周爬行」：关闭 / 偶尔（15%）/ 经常（40%）/ 一直爬（巡游，默认）；「爬行速度」：慢 / 中 / 快。
- 巡游中到了动作触发时间、又正好爬在底边时，她会停下来做吃饭、跳舞、节日等动作，然后接着爬。
- 点击：停下回应后继续；拖动：立即停止，放下后歇一会儿再从最近的边缘继续。
- 右键：「开始巡游 / 停止巡游」（其他模式为「沿屏幕爬一圈 / 停止爬行」）；停止时她会快步爬到底边再停下。
- 聊天、专注、玩游戏时自动停止爬行。

## 二、互动

- **双击聊天**：双击鱼鱼弹出输入框（Enter 发送，Shift+Enter 换行，Esc 收起），内置本地模型以鱼鱼的口吻多轮回答，回答显示在气泡中。
- **会淡忘的记忆**（`data\memory.json`）：
  - 每段对话按重要程度记忆：名字、生日等最重要，喜好、计划、心情次之，闲聊最容易忘。
  - 记忆强度随时间按遗忘曲线衰减；被想起一次就会记得更久。
  - 清楚的记忆可以自然提起；模糊的记忆会丢失数字和细节、时间可能记错；只剩印象的只记得大概话题；彻底淡忘的会被清理。
  - 聊天时根据主人说的话回忆相关片段，想不起来会老实说「记不太清了」。
  - 设置里可关闭记忆或一键清空。
- **称呼**：说「叫我小陈」「我叫××」后，她会用这个称呼；「叫我主人」可改回。
- **摸头**：鼠标在她头上左右来回轻划几下（不按键）。**戳戳**：单击有反应；短时间连戳会傲娇生气。
- **喂零食**：右键「喂零食…」（大白饭、小鱼干、冰淇淋、糖葫芦、西瓜、饺子），每天最多 6 次。
- **好感度与心情**（`data\bond.json`）：摸头、喂食、聊天、专注、陪伴时长都会增加好感（每天有上限），乱戳会减少；好感度分为初识 / 熟悉 / 亲近 / 亲密 / 心有灵犀，影响她聊天时的亲密程度。心情会随时间、饭点和互动变化。很多天没见时会说想你。
- **离开回来**：离开电脑 10 分钟以上再回来时挥手迎接。

## 三、关怀

- **久坐 / 喝水 / 护眼提醒**：按实际使用电脑的时间计算（默认 50 / 60 / 45 分钟，可调）；离开 5 分钟以上算作休息。
- **早安 / 催睡 / 晚安**：每天第一次用电脑（5–11 点）道早安；23:30 以后还在用电脑时每 30 分钟催睡（最多 4 次）；晚上关闭时说晚安。
- **番茄钟**：右键「专注 N 分钟」（默认 25 分钟、休息 5 分钟），专注时安静陪伴，不爬、不说话，提醒延后；聊天里说「开始专注」「结束专注」也可以。
- **定时提醒**（`data\reminders.json`）：右键「提醒事项…」或在聊天里说「30分钟后提醒我开会」「下午3点半提醒我交报告」「明天早上8:30叫我起床」。到点跳出提醒；重启后保留，错过的会补提醒。
- **游戏陪玩**：识别前台的常见游戏（Steam、Epic、WeGame、米哈游、暴雪、Riot 等，可在设置中补充进程名）：
  - 全屏不隐藏，鼠标点击穿过鱼鱼本体；
  - 游戏中不调用模型并释放模型占用的显存；
  - 开局加油、约每 20 分钟加油、每满 1 小时提醒休息、结束后关心战况；
  - 可选（实验，默认关闭）：每 15 秒本机 OCR 识别「胜利 / 失败」字样并做出反应。

所有新设置集中在 设置 → **互动与关怀**。

## 四、三角洲行动 · 烽火地带

前台是《三角洲行动》时（进程 `DeltaForceClient-Win64-Shipping`，Steam / WeGame / 官方启动器安装的都可以），鱼鱼会陪你打烽火地带：

- **识别画面**：约每 6 秒在本机截一次游戏画面并识别文字（Windows 自带的文字识别，不上传），只看画面上的大字，击杀信息、任务列表等小字不算：
  - 进图：加载画面的地图名（零号大坝、长弓溪谷、巴克什、航天基地、潮汐监狱、核电站）；
  - 撤离成功 / 撤离失败、阵亡、KIA / MIA；被击倒；结算画面的「带出价值」；
  - 全面战场的胜利 / 失败和复活画面会被认出来，不计入烽火战绩。
  - 同一个结算画面停着、切出去再回来，都只算一次；需要游戏使用「无边框窗口 / 窗口化全屏」，独占全屏可能截不到画面。
- **动作和吐槽**：
  - 进图：东张西望 / 原地踱步张望，「{地图}到了！耳朵竖起来听脚步～」；
  - 撤离成功：放烟花 / 金袋叮当 / 雀跃庆祝；三连撤以上跳舞；连寄之后终于撤出来会「感动哭」；进去几分钟就撤会夸你跑刀聪明；
  - 带出价值：百万以上「钱袋满溢」并记进记忆，三十万以上「金袋叮当」，十万以下「跑刀也是赚」；
  - 阵亡：袋空如洗 / 害羞惊讶 / 数金皱眉；进图三分钟内阵亡是「落地成盒」（垂头叹气冒汗）；连寄三把「气急败坏」并建议跑刀，连寄五把劝你休息（分文不剩）；
  - 被击倒：「倒了倒了！快爬到掩体后面！」；
  - 游戏中的加油台词换成烽火专属（听脚步、见好就收、小心老六……）。
- **战绩与复盘**（`data\deltaforce.json`）：今天（凌晨 5 点换日）和累计的撤离、阵亡、撤离率、连撤 / 连寄、最长连撤、带出的哈夫币、最近 40 局（时间、地图、用时、带出）。离开游戏 10 分钟后做一次复盘：今天几把、常去的图、最肥的一把，以及建议（连寄时跑刀缓一缓、撤离率高时冲大红、太晚了去睡觉等）。设置页可以看战绩、手动补记一把、清空战绩。
- **聊天时懂烽火**：聊到三角洲（或刚玩过 3 小时内）时，模型会拿到烽火黑话说明和今天的战绩；
  - 说「撤离成功了」「寄了」「被老六打死了」会记进战绩（屏幕已经认出来的不会重复记；说「不对，其实撤出来了」可以纠正刚才看错的一把）；
  - 说「出大红了」她会替你开心；问「今天战绩怎么样」「帮我复盘」会直接给出统计。
- **设置**：设置 → 互动与关怀 →「三角洲行动 · 烽火地带」：识别开关（需要开启游戏陪玩）、识别日志开关（`data\deltaforce-ocr.log`，只记录画面上的大字，识别不准时方便排查）、识别状态和战绩。

## 五、置顶 / 不置顶

- 右键「取消置顶 / 置顶显示」，或 设置 → 陪伴与外观 →「置顶显示（总在其他窗口前面）」，默认置顶。
- 取消置顶后，鱼鱼和普通窗口一样会被其他窗口挡住：点她、点托盘图标会把她叫到前面（不抢键盘焦点）。
- 定时提醒、专注结束、久坐 / 喝水 / 护眼提醒时，她会暂时跳到最前，气泡消失后回到窗口后面；开着游戏陪玩时，游戏在前台期间她仍待在游戏上面。
- 对话气泡、聊天框和小面板跟随她的置顶状态。

## 六、透明度

- 设置 → 陪伴与外观 →「透明度」滑块：0%（不透明）到 80%，只改变鱼鱼本身，对话气泡保持清晰。
- 「鼠标移到鱼鱼身上时恢复不透明」（默认开启），方便点她、拖她。

## 七、三角洲里模仿主人

开启「游戏陪玩」且前台是《三角洲行动》时，鱼鱼会同步模仿你的操作（设置 → 互动与关怀 →「三角洲行动 · 烽火地带」里可关闭）：

- **开枪**：按下左键她就举起水枪（「玩水枪」动作中举枪的一段），每一发都有枪口火光、后坐抖动，偶尔弹出弹壳；按住连射约每秒 9 发。
- **瞄准**：按住右键（或单击右键切换开镜）时，她的枪口前出现准星。
- **受伤**（实验）：每 0.2 秒看一眼画面边缘和准星周围，突然变红时她全身红闪、抖一下，偶尔「被吓一跳」；被击倒时更强烈。
- **缠绷带 / 打药 / 吃药**：松开治疗键（游戏默认 5）时她先拿出急救包，随后看一眼画面中间的物品名，换成对应动作：白色绷带一圈圈缠上、针筒推进手臂、药丸落进嘴里「咕嘟～」，最后冒出绿色「+」。如果你单独绑定了绷带 / 针剂 / 止痛药键，可在设置里选上，直接对应。
- 开枪和瞄准只在鼠标指针隐藏（正在操作角色）时才算，打开背包、地图等界面时不会误判；切到其他窗口时自动停止。
- 只读取按键状态和屏幕画面，不向游戏发送任何操作、也不读取游戏内存。
- 现有动画中没有开枪、包扎等动作，这些道具和特效是在鱼鱼身上实时绘制的。

## 八、构建

与上游相同，需要 Windows x64 和 .NET 10 SDK。无MCP版：

```powershell
dotnet build ./code/BigBlueFish.Windows/BigBlueFish.Windows.csproj -c Release -p:Platform=x64 -p:CompanionEdition=Safe -p:CompanionInputMode=Ocr -p:RestoreLockedMode=true -p:InformationalVersion=1.0.5-companion.4
```

把 `code/BigBlueFish.Windows/bin/x64/Release/net10.0-windows10.0.26100.0/` 中的 `BigBlueFish.dll`、`BigBlueFish.pdb` 替换到已安装的官方 v1.0.5 程序目录即可（请先备份原文件）。
