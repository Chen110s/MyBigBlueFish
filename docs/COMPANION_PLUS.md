# MyBigBlueFish 修改说明

本仓库基于 [Bai-Cute/big-blue-fish-desktop-pet](https://github.com/Bai-Cute/big-blue-fish-desktop-pet) 的 v1.0.5（Apache License 2.0）修改。原作者的代码、动画素材（来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，MIT）、许可文件和第三方声明均保持不变；下面列出本仓库新增和修改的内容。

修改后的程序在设置页左侧显示版本号 `1.0.5-companion.16`（构建时传入 `-p:InformationalVersion=1.0.5-companion.16`）。所有新增数据都只保存在本机安装目录的 `data\` 中，不上传。

## 一、沿屏幕四周爬行

- 鱼鱼用「螃蟹走路」动作沿当前显示器的可用区域（不含任务栏）四周横着爬：底边站立，左右两侧贴墙（旋转 ±90°），顶边倒挂（180°），拐角处顺势转身且始终贴着两条边。
- 设置 → 陪伴与外观 →「沿屏幕四周爬行」：关闭 / 偶尔（15%）/ 经常（40%）/ 一直爬（巡游，默认）；「爬行速度」：慢 / 中 / 快。
- 巡游中到了动作触发时间、又正好爬在底边时，她会停下来做吃饭、跳舞、节日等动作，然后接着爬。
- 点击：停下回应后继续；拖动：立即停止，放下后歇一会儿再从最近的边缘继续。
- 右键：「开始巡游 / 停止巡游」（其他模式为「沿屏幕爬一圈 / 停止爬行」）；停止时她会快步爬到底边再停下。
- 聊天、专注、玩游戏时自动停止爬行。

## 二、互动

- **双击聊天**：双击鱼鱼弹出输入框（Enter 发送，Shift+Enter 换行，Esc 收起），内置本地模型以鱼鱼的口吻多轮回答，回答显示在气泡中。
- **会淡忘的记忆**（`data\memory.json`）：
  - 每段对话按重要程度记忆：名字、生日等最重要，喜好、计划、心情次之，闲聊最容易忘。
  - 记忆强度随时间按遗忘曲线衰减；被想起一次就会记得更久。
  - 清楚的记忆可以自然提起；模糊的记忆会丢失数字和细节、时间可能记错；只剩印象的只记得大概话题；彻底淡忘的会被清理。
  - 聊天时根据主人说的话回忆相关片段，想不起来会老实说「记不太清了」。
  - 设置里可关闭记忆或一键清空。
- **称呼**：说「叫我小陈」「我叫××」后，她会用这个称呼；「叫我主人」可改回。
- **摸头**：鼠标在她头上左右来回轻划几下（不按键）。**戳戳**：单击有反应；短时间连戳会傲娇生气。
- **喂零食**：右键「喂零食…」（大白饭、小鱼干、冰淇淋、糖葫芦、西瓜、饺子），每天最多 6 次。
- **好感度与心情**（`data\bond.json`）：摸头、喂食、聊天、专注、陪伴时长都会增加好感（每天有上限），乱戳会减少；好感度分为初识 / 熟悉 / 亲近 / 亲密 / 心有灵犀，影响她聊天时的亲密程度。心情会随时间、饭点和互动变化。很多天没见时会说想你。
- **离开回来**：离开电脑 10 分钟以上再回来时挥手迎接。

## 三、关怀

- **久坐 / 喝水 / 护眼提醒**：按实际使用电脑的时间计算（默认 50 / 60 / 45 分钟，可调）；离开 5 分钟以上算作休息。
- **早安 / 催睡 / 晚安**：每天第一次用电脑（5–11 点）道早安；23:30 以后还在用电脑时每 30 分钟催睡（最多 4 次）；晚上关闭时说晚安。
- **番茄钟**：右键「专注 N 分钟」（默认 25 分钟、休息 5 分钟），专注时安静陪伴，不爬、不说话，提醒延后；聊天里说「开始专注」「结束专注」也可以。
- **定时提醒**（`data\reminders.json`）：右键「提醒事项…」或在聊天里说「30分钟后提醒我开会」「下午3点半提醒我交报告」「明天早上8:30叫我起床」。到点跳出提醒；重启后保留，错过的会补提醒。
- **游戏陪玩**：识别前台的常见游戏（Steam、Epic、WeGame、米哈游、暴雪、Riot 等，可在设置中补充进程名）：
  - 全屏不隐藏；游戏在前台时鼠标点击总会穿过鱼鱼和她的对话气泡（切到游戏的一瞬间生效，与是否开启陪玩无关），游戏中的提醒气泡 15 秒后自动收起；
  - 游戏中不调用模型并释放模型占用的显存；
  - 开局加油、约每 20 分钟加油、每满 1 小时提醒休息、结束后关心战况；
  - 可选（实验，默认关闭）：每 15 秒本机 OCR 识别「胜利 / 失败」字样并做出反应。

所有新设置集中在 设置 → **互动与关怀**。

## 四、三角洲行动 · 烽火地带

前台是《三角洲行动》时（进程 `DeltaForceClient-Win64-Shipping`，Steam / WeGame / 官方启动器安装的都可以），鱼鱼会陪你打烽火地带：

- **识别画面**：约每 6 秒在本机截一次游戏画面并识别文字（Windows 自带的文字识别，不上传），只看画面上的大字，击杀信息、任务列表等小字不算：
  - 进图：加载画面的地图名（零号大坝、长弓溪谷、巴克什、航天基地、潮汐监狱、核电站）；
  - 撤离成功 / 撤离失败、阵亡、KIA / MIA；被击倒；结算画面的「带出价值」；
  - 全面战场的胜利 / 失败和复活画面会被认出来，不计入烽火战绩。
  - 同一个结算画面停着、切出去再回来，都只算一次；需要游戏使用「无边框窗口 / 窗口化全屏」，独占全屏可能截不到画面。
- **动作和吐槽**：
  - 进图：东张西望 / 原地踱步张望，「{地图}到了！耳朵竖起来听脚步～」；
  - 撤离成功：放烟花 / 金袋叮当 / 雀跃庆祝；三连撤以上跳舞；连寄之后终于撤出来会「感动哭」；进去几分钟就撤会夸你跑刀聪明；
  - 带出价值：百万以上「钱袋满溢」并记进记忆，三十万以上「金袋叮当」，十万以下「跑刀也是赚」；
  - 阵亡：袋空如洗 / 害羞惊讶 / 数金皱眉；进图三分钟内阵亡是「落地成盒」（垂头叹气冒汗）；连寄三把「气急败坏」并建议跑刀，连寄五把劝你休息（分文不剩）；
  - 被击倒：「倒了倒了！快爬到掩体后面！」；
  - 游戏中的加油台词换成烽火专属（听脚步、见好就收、小心老六……）。
- **战绩与复盘**（`data\deltaforce.json`）：今天（凌晨 5 点换日）和累计的撤离、阵亡、撤离率、连撤 / 连寄、最长连撤、带出的哈夫币、最近 40 局（时间、地图、用时、带出）。离开游戏 10 分钟后做一次复盘：今天几把、常去的图、最肥的一把，以及建议（连寄时跑刀缓一缓、撤离率高时冲大红、太晚了去睡觉等）。设置页可以看战绩、手动补记一把、清空战绩。
- **聊天时懂烽火**：聊到三角洲（或刚玩过 3 小时内）时，模型会拿到烽火黑话说明和今天的战绩；
  - 说「撤离成功了」「寄了」「被老六打死了」会记进战绩（屏幕已经认出来的不会重复记；说「不对，其实撤出来了」可以纠正刚才看错的一把）；
  - 说「出大红了」她会替你开心；问「今天战绩怎么样」「帮我复盘」会直接给出统计。
- **设置**：设置 → 互动与关怀 →「三角洲行动 · 烽火地带」：识别开关（需要开启游戏陪玩）、识别日志开关（`data\deltaforce-ocr.log`，只记录画面上的大字，识别不准时方便排查）、识别状态和战绩。

## 五、置顶 / 不置顶

- 右键「取消置顶 / 置顶显示」，或 设置 → 陪伴与外观 →「置顶显示（总在其他窗口前面）」，默认置顶。
- 取消置顶后，鱼鱼和普通窗口一样会被其他窗口挡住：点她、点托盘图标会把她叫到前面（不抢键盘焦点）。
- 定时提醒、专注结束、久坐 / 喝水 / 护眼提醒时，她会暂时跳到最前，气泡消失后回到窗口后面；开着游戏陪玩时，游戏在前台期间她仍待在游戏上面。
- 对话气泡、聊天框和小面板跟随她的置顶状态。

## 六、透明度

- 设置 → 陪伴与外观 →「透明度」滑块：0%（不透明）到 80%，只改变鱼鱼本身，对话气泡保持清晰。
- 「鼠标移到鱼鱼身上时恢复不透明」（默认开启），方便点她、拖她。

## 七、形象包切换

- 设置 → 陪伴与外观 →「形象」：在原版蓝色大肥鱼和程序目录 `skins\` 里的形象包之间切换，选中立即生效，随时可换回原版。
- 形象包 = `skins\` 下的一个子文件夹，放入以动作命名的透明背景动画（如 `待机呼吸休闲.webm`、`点击回应-元气挥手.gif`）；支持 VP9 WebM（带透明通道）、GIF、APNG、MOV 和静态 PNG（当作 3 秒的动作），任意尺寸和帧率都会等比缩放到 640×360、贴底居中、24 帧/秒。
- 缺少的动作默认用形象包自己的待机动作代替，随机动作只从形象包提供的动作里挑；`skin.json` 里写 `"Missing": "fish"` 则沿用原版鱼鱼。可选 `animations.json` 增加原版没有的新动作。
- 「打开形象包文件夹」会生成「形象包说明.txt」和全部 106 个动作名的「动作清单.txt」。
- 某个动作播放失败时自动换回原版并提示，不会让鱼鱼卡住。
- 形象包的动画默认按整段播放（不使用原版动画里的分段），游戏模仿时的枪口火光只在原版形象下显示；`skin.json` 写 `"SameTiming": true`（每个动作与原版逐帧对应，例如调色版）时，分段、走动和水枪特效与原版完全一致。
- 附带四套原版调色形象包：樱粉鱼鱼、薄荷鱼鱼、和风绯红鱼鱼、暗夜鱼鱼（只改变头发、眼睛、鱼尾等蓝色部分，106 个动作齐全）。
- 附带 13 套鲸鱼娘成长期与衍生形象，素材来自同人游戏《鲸鱼娘养成计划》（[Anria-2026/xiaojingyu-open-source](https://github.com/Anria-2026/xiaojingyu-open-source)，作者 Anria_；美术素材 CC BY-NC-SA 4.0，仅限非商业使用，上游形象致谢上善无形、ZipZipPipe）：
  - 成长期 · 10 岁童年、15 岁少女、20 岁青年、25 岁成熟：游戏结局里各年龄的行走动画（带透明通道）和站姿，年龄越大个子越高；
  - Q版女仆鲸鱼娘：站立、睡觉、欢呼、跳跃、头晕、抡锤、奔跑、举饭盆、魔杖等姿势；
  - 换装 × 8：节日红装、卫衣耳机、偶像演出、白大褂、月亮睡衣、鲸鱼睡衣、冬日围巾、夏日浴衣，各有站立、跳起、睡觉、魔杖四个姿势。
  - 每套缩放到 640×360（贴底居中），加上待机摇摆、哼歌、小憩、跳跃、挥手、害羞、生气、屈膝礼、被拖动、吐泡泡、思考、转圈、摇摆舞、庆祝、放烟花、金币等 22～29 个动作和特效，渲染成透明 VP9 WebM；其余动作用它的待机动作代替。每个形象包里附带说明和原项目的许可文件；改编后的形象包同样按 CC BY-NC-SA 4.0 提供。
- 形象轮换：「自动轮换形象，每 N 分钟换一次」（5 分钟～4 小时，默认关闭），随机换、不连续重复，可选原版是否参与；被拖动、沿屏幕爬行或在三角洲里模仿时会稍后再换。「换一个」按钮可马上换。

## 八、招商银行金价

- 数据来自招行一网通「黄金市场行情」（https://m.cmbchina.com/goldrate.html，即招行展示的上海黄金交易所行情），可选 Au99.99（默认）、Au(T+D)、Au100g、Au99.95、Ag(T+D)、Pt99.95。
- 更新频率在设置里选：每秒 / 每分钟（默认）/ 每十分钟 / 每小时 / 每天。交易时段（9:00–11:30、13:30–15:30、20:00–次日 2:30）照选的频率更新；休市时价格不动，最多每 10 分钟看一次（选每小时、每天时照选的来）。旧版保存的间隔自动换成最接近的一档。
- 价格每次变化都追加到 `data\gold-records.csv`（记录时间、行情时间、品种、最新价、涨跌、涨跌幅、开盘、昨收、最高、最低；超过 5 MB 自动换新文件）。
- 比上次播报涨跌超过设定值（默认 5 元/克）时，鱼鱼播报并配动作（涨：金袋叮当，跌：数金皱眉）；玩游戏、专注时不打扰。
- 可设「高于 / 低于」提醒价，越过时重要提醒（隐藏时走系统通知），回落后重新生效。
- **金价变动提醒**（设置里可开关，默认打开）：价格每变一次，鱼鱼用气泡报当时的金价，例如「招行 Au99.99 1023.45 元/克 ↑0.32（14:05:07，今天 +6.80）」——涨了是红字，跌了是绿字。玩游戏、专注、聊天、拖动、隐藏时不打扰，也不盖住气泡里还在显示的其他话（上一条变动提醒会被新价格替换）。涨跌播报和到价提醒的气泡也按涨红跌绿着色。
- 右键「招行金价」、聊天问「金价多少」直接给出最新价、今日涨跌、最高最低；设置页显示今日走势小图和最近的变化，可打开记录文件。
- **金价推测（天 / 周 / 月 / 年）**：用上海黄金交易所同一品种的历史日线（东方财富，2010 年起，缓存在 `data\gold-history-*.csv`，每 3 小时增量更新）推算下个交易日、一周、一个月、一年后的价格区间：
  - 波动：近期日波动按指数加权（λ = 0.97）估计，并随周期逐渐回到近 3 年的平均水平（持续系数 0.985）；
  - 趋势：只取长期平均涨幅的一半，再给趋势本身加 ±10%/年 的不确定性（主要放宽一年的区间）；
  - 区间：中间值 ± 1.0 σ（约 68%）和 ± 2.2 σ（约 95%，黄金有厚尾，比正态的 1.96 宽）；另给出历史上同样周期上涨的比例，以及现价相对 20 / 60 / 250 日均线的位置、近 20 日涨跌、距一年高点的距离；
  - 回测（Au99.99，2013–2026 每个交易日滚动推算）：天 / 周 / 月的 68% 区间命中约 72–75%、95% 区间约 95%；最近三年行情剧烈，月度 95% 区间降到约 90%；一年的区间全期约 66% / 95%，但在 2024–2025 年大涨中明显失准（最近三年只有约 17% / 73%），所以只能当个大概；
  - 周期从最后一根日线算起；那根日线还在交易时（盘中），每个周期多算半天的波动；
  - 每个交易日第一次推测（历史日线刚更新、基准是现价或已收盘的价格时）记到 `data\gold-forecasts.csv`，到期后自动对答案（设置页显示命中次数和平均误差）；Au100g 借用 Au99.99 的日线，不记录；
  - 设置页「招商银行金价」下有推测摘要和「打开金价面板」；聊天问「金价预测」「明天金价会涨吗」「黄金下个月走势」会回答对应周期；右键「招行金价」用气泡报价和今天的预计，「金价面板…」看表格。问到买卖时鱼鱼会说明她不是理财顾问；问的是另一种金属（例如盯着黄金却问白银）时，她会提示先在设置里换品种，不拿错的数字回答；「黄金周」「黄金段位」之类不当成金价问题。
  - 这是统计推算，不是预言，也不构成投资建议。
- **右键「招行金价」**：鱼鱼用聊天气泡报现价、今日涨跌、开盘 / 最高 / 最低，以及「今天收盘」（收盘后是「明天」或「下周一」）的预计区间——按当前波动和剩下的交易时间推算（夜盘 20:00–2:30 算下一交易日，日盘 9:00–11:30、13:30–15:30，共 11 小时），再附国际金价和人民币汇率当日的变化。聊天问「金价多少」「今天金价会涨吗」也是这段话。
- **金价面板（表格）**：右键「金价面板…」打开独立窗口，最上面是和气泡一样的摘要，下面按「一、金价变化 → 二、金价预测 → 三、买卖参考 → 四、判断依据」排列，全部用表格展示：
  - 实时行情：招行全部黄金 / 白银 / 铂金品种的最新价、涨跌、开盘、昨收、最高、最低，正在盯的品种高亮；
  - 价格走势折线图：今天、近 7 天（招行实时报价记录）以及 1 个月 / 3 个月 / 1 年 / 3 年 / 全部（日线），带 20 日均线、未来 68% 推测扇形、计划价位虚线，鼠标悬停显示日期和价格；
  - 今天收盘 / 天 / 周 / 月 / 年推测表；
  - 判断因素表：国际金价（伦敦金 / 伦敦银）、美联储预期（美债 2 年、10 年收益率）、美元指数、避险情绪（标普 500）、央行购金（按月公布，只作背景）、人民币汇率（离岸人民币与中间价）、产品点差——每项给出最新值、近 20 个交易日变化、一般规律和现在的情况（↑ 偏支撑 / ↓ 偏压力）；数据来自东方财富日线，打开面板时下载、每 30 分钟更新；
  - 国内金价拆解：国内金价 ≈ 国际金价 × 美元兑人民币 ÷ 31.1035 + 国内溢价，并把近 20 个交易日的涨跌拆成国际价格、汇率和溢价三部分；
  - 点差成本与回本：填入产品点差（买入价 − 回购价），给出各持有期的回本价、到期涨过回本价的统计概率、点差占典型波动的比例；
  - 我的计划价位：计划买入价 / 卖出价（即「低于 / 高于」提醒价），显示距现价、一周 / 一个月内按波动粗算的触及概率和提醒状态；两个都设时给出扣点差后的差价；
  - 历史参考价位：近 20 / 60 / 250 个交易日和全部历史的最高（日期）、最低（日期）、均价和现价位置。
  - 回测（2011–2026）：这些因素很能解释已经发生的涨跌（国内金价 20 日涨跌与「国际金价 + 汇率」相关约 0.95），但对下个月涨跌几乎没有预测力（相关不到 0.1），所以推测区间不按它们调整，只作判断参考。面板不给买卖建议，买不买、什么时候买由你决定。

## 九、三角洲里模仿主人

开启「游戏陪玩」且前台是《三角洲行动》时，鱼鱼会同步模仿你的操作（设置 → 互动与关怀 →「三角洲行动 · 烽火地带」里可关闭）：

- **开枪**：按下左键她就举起水枪（「玩水枪」动作中举枪的一段），每一发都有枪口火光、后坐抖动，偶尔弹出弹壳；按住连射约每秒 9 发。
- **瞄准**：按住右键（或单击右键切换开镜）时，她的枪口前出现准星。
- **受伤**（实验）：每 0.2 秒看一眼画面边缘和准星周围，突然变红时她全身红闪、抖一下，偶尔「被吓一跳」；被击倒时更强烈。
- **缠绷带 / 打药 / 吃药**：松开治疗键（游戏默认 5）时她先拿出急救包，随后看一眼画面中间的物品名，换成对应动作：白色绷带一圈圈缠上、针筒推进手臂、药丸落进嘴里「咕嘟～」，最后冒出绿色「+」。如果你单独绑定了绷带 / 针剂 / 止痛药键，可在设置里选上，直接对应。
- 开枪和瞄准只在鼠标指针隐藏（正在操作角色）时才算，打开背包、地图等界面时不会误判；切到其他窗口时自动停止。
- 只读取按键状态和屏幕画面，不向游戏发送任何操作、也不读取游戏内存。
- 现有动画中没有开枪、包扎等动作，这些道具和特效是在鱼鱼身上实时绘制的。

## 十、动画自检与自动恢复

动画由自带的解码器（`media\ffmpeg.exe`）逐帧解出。以前只要有一次没播出来，鱼鱼就停下并提示「动画未能播放，请检查动画组件是否完整」，要重启才能恢复；现在：

- **自检**：哪个动作失败，她就检查解码器和动画文件在不在、解码器的退出码是什么，把结果连同本进程的 GDI / USER 对象数、句柄数、内存和运行时长追加到 `data\companion-errors.log`（不再覆盖之前的记录；超过 256 KB 时旧日志改名为 `.old`）。
- **自动重试**：分别隔 2 秒、8 秒、18 秒再播一次；三次都失败才停下，并用气泡说出自检得出的原因（例如解码器被安全软件隔离、系统资源暂时用尽 0xC0000142、文件损坏）。停下后每分钟再试一次，一旦能播放就自己恢复并告诉你。
- **退出保障不再致命**：解码器启动后会被放进一个「随鱼鱼一起结束」的作业对象，只是防止残留进程的保险。Windows 拒绝时（解码器已经退出，或别的软件把鱼鱼放进了另一个作业）不再中止播放，只在日志里记一笔（每小时最多一次）。
- 形象包的动作失败时，仍然自动换回蓝色大肥鱼。

## 十一、互动手感、跑动与触发规则（参考 dsh-whale-pet）

玩法参考 [luweiyabo/dsh-whale-pet](https://github.com/luweiyabo/dsh-whale-pet)（DeepSeek Harness 网页版的鲸鱼桌宠插件），在这里用 WPF 重新实现。设置 → 陪伴与外观 →「互动手感与动作」里每一项都能单独关闭；Windows 关闭了「显示动画」时，倾斜、回弹和甩出滑行自动停用。

- **悬停注视**：鼠标在她身体左半边 / 右半边时转向那一侧，移开后恢复；画面里带文字的动作（写福字、深度思考等）不镜像；鼠标在她头上时不翻转，免得摸头摸到一半转身。
- **交互动效**：光标靠近（左右 140 像素以内）时，她向光标轻轻倾斜（最多 3.5°，弹簧缓动）；点她一下先压扁再弹起，连点会更 Q；拖动时沿移动方向轻微拉伸，落下时小小回弹。
- **点击分区**：头 → 害羞惊讶 / 傲娇生气；身体 → 元气挥手 / 开心跃动；尾巴 → 挠痒咯咯笑，偶尔用鲸鱼尾巴拍地。动作库里加入「点击回应」池的其他动作在所有部位都会出现。
- **快速甩出**：松手时速度够快，她从「变成球」的球形开始滑出去，速度按指数衰减，碰到屏幕边反弹（法向速度保留 78%）并挤压一下，贴地滑行时摩擦更大；停下后动画自然播完、站起来。
- **藏到屏幕边**：把她整个拖出所有显示器，她就贴着最近那条边藏起来；鼠标移到那条边、靠近她的位置时探出约四成身体，有话要说时也会探出来；点她就回到屏幕上并挥手，也可以直接拖回来；托盘「显示桌宠」同样能叫她回来。
- **点屏幕让她跑过去**：单击鱼鱼后，屏幕会蒙上一层很淡的蓝色、指针变成十字，5 秒内点任意位置，她用「预备姿势奔跑」跑过去（目标在别的显示器时跑到自己显示器上最近的位置），到了「原地挥手打招呼」。这一层只接住这一下点击，不会点到下面的窗口，也不抢键盘焦点；右键、再点她或 5 秒不点就取消。玩游戏、专注、聊天、爬行时不进入选位置。
- **活跃程度**：安静（动作间隔 ×1.5，只在原地演，不走路、不随机爬行）/ 均衡（和以前一样）/ 活泼（间隔 ×0.6，三成机会自己小跑一段）。
- **聊天状态**：聊天框里打字时「侧耳倾听」，本地模型生成时（加载圈出现）「深度思考碎碎念」，聊天出错或走神时「被吓一跳」；状态变高 0.3 秒后切换、变低时停留 1.2 秒，避免闪来闪去，状态持续时动作循环。
- **动作库**（右键「动作库…」）：按 dsh-whale-pet 的分类（待机、移动、点击回应、日常、工作、游戏、音乐舞蹈、美食、节日、四季、魔术、趣味、鲸鱼特色、梗图、余额、碎碎念等）浏览全部动作，可搜索、在窗口里循环预览（换了形象包时预览形象包的同名动作）、让她立刻演一遍；每个动作可以放进「随机动作」「点击回应」「待机」「不自动播放」或保持原用途，保存在 preferences 的 `PoolOverrides` 里；某个池里没有随时能播的动作时，这次修改不生效。
- **触发规则**（动作库或设置里的「触发规则…」）：事件可选鱼鱼启动、主人离开后回来、整点、切换到某个程序、点鱼鱼（头 / 身体 / 尾巴）、摸头、喂零食、聊天时你说的话、鱼鱼回答完、聊天出错、提醒到点、关怀提醒、开始 / 结束专注、开始 / 结束游戏、三角洲进图 / 撤离 / 阵亡 / 被击倒、金价变动（可限定涨 / 跌和单次变动幅度）、金价到提醒价；每条规则可选多个动作（随机演一个）、一句气泡（支持 {称呼} {时间} {内容} {数值} {价格} {变动} 等占位符）、优先级和冷却时间，并能「试一下」。同一事件只触发优先级最高的一条；鱼鱼本来就要说的话（提醒、到价、专注完成、回答等）不会被盖住，规则的话接在下面；金价变动有规则时代替内置的变动提醒。规则保存在 `data\trigger-rules.json`。
- **优先级**：你拖她、点她（2.5 秒内）、她在跑 / 爬 / 甩出 / 模仿三角洲、Agent 动作和动作库预览都不会被打断；聊天状态和规则按优先级抢占（倾听 30、思考 40、出错 60，规则默认 50）。
- **新增的 4 个动作素材**：「预备姿势奔跑」「变成球」「侧耳倾听」「原地挥手打招呼」取自 dsh-whale-pet（提交 b61b445），由构建脚本从 `edge-crawl\clips` 复制到程序的 `assets\fish`。dsh-whale-pet 的 MIT 许可只覆盖代码，动画素材按其上游 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的条款（允许开源使用、禁止商用）和形象的 CC BY-NC-SA 4.0 使用，所以只在本机使用、没有放进本仓库；说明见 `assets\fish\dsh-whale-pet-LICENSE.txt`。没有这些文件时，跑动用螃蟹走路、倾听用东张西望、挥手用元气挥手代替，甩出时不变球。

## 十二、DeepSeek 网页版与聊天记录

- **DeepSeek 网页版**：右键「DeepSeek 网页版…」（或 设置 → 互动与关怀 → 聊天与记忆 →「打开 DeepSeek 网页版…」）用 Microsoft Edge WebView2 打开官方网页版 chat.deepseek.com。你自己登录、像在浏览器里一样免费聊；登录信息保存在 `data\webview2`。窗口上方有「保存这次对话」「打开保存文件夹」「刷新」「在浏览器中打开」。弹出的链接：DeepSeek 自己的页面在同一窗口打开，其他网站交给默认浏览器。
- **不做自动对接**：DeepSeek 用户协议（3.5、5.1 条）不允许用机器人、自动程序抓取或镜像网页版内容，也不允许逆向，所以鱼鱼不会替你在网页里发消息，也不会在后台读取页面；只有你点「保存这次对话」时，才读一次当前页面上的对话（优先按消息分成「你」和「DeepSeek」，认不出时保存整块对话区的文字），存成 `DeepSeek-日期时间-标题.md`。你在网页版窗口里操作时，鱼鱼会在旁边侧耳倾听（只看有没有键盘鼠标操作，不看内容）。
- **聊天记录**：鱼鱼聊天框里的每一轮（你说的话和她的回答，不管来自本地模型还是她自己的功能）追加到 `鱼鱼聊天-yyyy-MM-dd.md`，可在设置里关闭。保存位置默认 `data\chats`，可「选择文件夹…」改成已有的文件夹；那个文件夹不在了就暂时存回默认位置。
- **组件**：NuGet 包 Microsoft.Web.WebView2 1.0.4258.31（BSD 风格许可）；`Microsoft.Web.WebView2.*.dll` 和 `WebView2Loader.dll` 由构建脚本复制到程序目录，程序在打开网页版窗口时才加载它们。没有 WebView2 运行时的电脑会提示下载（Windows 11 自带）。
